# ISO/IEC 相关标准

本体与知识图谱领域涉及的国际标准，主要来自 ISO/IEC JTC 1（信息技术）、ISO/TC 37（术语）、ISO/TC 184/SC 4（工业数据）等。

> ISO 标准原文通常通过 ISO 商店或成员国成员机构获取，下方链接为官方条目页。

## 工业与领域（部分相关）

- ISO 10303 (STEP) / ISO 13399 系列：工业数据交换，常与本体映射结合
- ISO 15926：流程工业全生命周期数据集成
- ISO 8000：数据质量（与知识图谱数据治理相关）
