# 行业本体与通用上层本体

上层本体（Top-level Ontology）为领域本体提供公共概念基础；行业本体则面向具体领域的概念体系与推理需求。

## 通用上层本体

| 名称 | 全称 | 链接 | 特点 |
|---|---|---|---|
| BFO | Basic Formal Ontology | https://github.com/BFO-ontology/BFO-2020 | ISO 21838-2，生命科学/制造常用 |
| DOLCE | Descriptive Ontology for Linguistic and Cognitive Engineering | http://www.loa.istc.cnr.it/dolce/overview.html | 语言认知工程，ISO 21838-4 |
| SUMO | Suggested Upper Merged Ontology | https://github.com/ontologyportal/sumo | 数学化通用本体 |
| GFO | General Formal Ontology | https://github.com/Onto-Med/GFO | 德国莱比锡大学，ISO 21838-3 |
| CCO | Common Core Ontologies | https://github.com/CommonCoreOntology/CommonCoreOntologies | 美军/国防领域扩展 |
