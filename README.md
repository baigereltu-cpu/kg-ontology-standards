# Awesome Knowledge Graph & Ontology Standards

本体（Ontology）与知识图谱（Knowledge Graph）相关标准的统一索引。覆盖 W3C 语义网栈、ISO/IEC、IEEE、中国国家标准（GB/T）、行业本体与常用工具链，每个条目尽量给出**官方链接**。

> ⚠️ 标准状态会随时间变化：ISO/IEEE 标准需通过官方平台购买或确认，GB/T 以全国标准信息公共服务平台 `std.samr.gov.cn` 为准，W3C 规范以 `w3.org/TR/` 为准。本文档只做索引，不替代标准原文。

## 按技术路线速分

| 技术路线 | 代表标准 | 典型场景 |
|---|---|---|
| 语义网/RDF 派 | RDF · RDFS · OWL · SPARQL · SHACL · JSON-LD | 推理、跨系统互操作、数据集成 |
| 属性图派 | GQL(ISO/IEC 39075) · SQL/PGQ | 图数据库、关系网络分析 |
| 元数据/词表 | Dublin Core · SKOS · DCAT · Schema.org | 目录、分类法、网页结构化 |
| 上层/领域本体 | BFO · DOLCE · SUMO · FIBO · SNOMED CT | 本体工程、行业落地 |
| 国内合规 | GB/T 42131 · GB/T 45628 · GB/T 46686 等 | 国内项目验收、平台建设 |
