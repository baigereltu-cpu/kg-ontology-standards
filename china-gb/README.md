# 中国国家标准（GB/T）知识图谱相关

国内本体与知识图谱标准化工作主要由全国信息技术标准化技术委员会（TC 28）人工智能分委会等推动，已发布与在研标准覆盖技术框架、知识交换、平台建设、标准知识图谱与标准数字化。

## 官方查询入口

- [全国标准信息公共服务平台](https://std.samr.gov.cn/)
- [国家标准全文公开系统](https://openstd.samr.gov.cn/)

> 以下标准号与名称为整理时状态，实际状态（现行/即将实施/废止）与可获取文本请以官方平台检索为准。

|---|---|---|---|
| GB/T 42131-2022 | 人工智能 知识图谱技术框架 | 现行 | 知识图谱总体技术框架 |

| GB/T 42132 系列 | 人工智能 知识图谱 评估与测试 | 在研/部分发布 | 质量与评估 |

## 提示

- 标准发布后通常有一段"即将实施"过渡期，注意生效日期。
- 国标全文公开系统对部分标准提供在线阅读，下载可能受限。
- 行业与团体标准分散在工信部、能源局、学会等平台，需分别查询。
