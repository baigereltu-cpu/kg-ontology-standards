# IEEE 知识图谱系列标准

IEEE 标准协会（IEEE SA）知识工程标准委员会（KESC）主导了知识图谱相关标准，覆盖术语、参考架构、行业应用等。

## 总入口

- [IEEE KESC Standards & Projects](https://sagroups.ieee.org/kesc/standards-or-projects/)

## 标准清单

| 标准号 | 名称 | 状态 | 说明 |
|---|---|---|---|
| IEEE 2807-2022 | Standard for Framework and Requirements of Knowledge Graphs | 已发布 | 知识图谱框架与要求 |
| IEEE 2807.1 | 知识图谱架构 | 进行中 | 参考架构 |
| IEEE 2807.2 | 知识图谱术语 | 进行中 | 术语体系 |
| IEEE 2807.3-2022 | Guide for Electric Power Industry Knowledge Graph | 已发布 | 电力行业知识图谱指南 |
| IEEE P2807.4 | 知识图谱数据交换协议 | 进行中 | 数据交换 |
| IEEE P2807.5 | 知识图谱应用平台性能测试 | 进行中 | 性能与测试 |
| IEEE P2807.6 | 医学知识图谱 | 进行中 | 医疗行业应用 |

## 说明

- IEEE 标准原文发布于 [IEEE Xplore](https://ieeexplore.ieee.org/)，部分需订阅或购买。
- 部分在研项目（P 开头）状态可通过 KESC 官网跟踪。
- 中国团体/行业标准（如 T/CESA 系列）常与 IEEE 2807 协同推进。
