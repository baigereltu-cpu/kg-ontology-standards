# 工具链与开源实现

将标准落地为可用系统，需要配套的建模、存储、查询、推理、校验与可视化工具。

## RDF 存储与图数据库

| 工具 | 链接 | 说明 |
|---|---|---|
| Apache Jena | https://jena.apache.org/ | RDF 框架，Fuseki SPARQL Server |
| RDF4J | https://rdf4j.org/ | Eclipse RDF 框架与存储 |
| GraphDB | https://graphdb.ontotext.com/ | 商业/免费版 RDF 数据库 |
| Virtuoso | https://virtuoso.openlinksw.com/ | 多模型数据库，支持 SPARQL |
| Stardog | https://www.stardog.com/ | 企业级知识图谱平台 |
| Blazegraph | https://github.com/blazegraph/database | 高性能 RDF 三元组库 |
